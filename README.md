## 🧠 Adaptive SOC Training Environment

This investigation was completed within ECPI University's AEGIS SOC training environment, which used an adaptive, AI-supported workflow to generate and evaluate analyst ticket assignments.

Rather than providing identical incidents that directly mirrored each lab handout, the environment assigned SOC tickets based on the security skills and investigative competencies being developed. As a result, the specific incident presented in Zammad could differ from the scenario described in the accompanying lab documentation.

Analysts were expected to investigate the evidence actually present in their assigned ticket using Wazuh SIEM, correlated security telemetry, and Zammad case management rather than force the findings to match the example scenario.

For this assignment, although the accompanying lab focused on IDOR and API abuse, the assigned ticket contained evidence of unauthorized SSH activity, root-level command execution, log deletion and tampering, defense evasion, and suspicious outbound communication. The investigation and final report therefore documented the activity supported by the available evidence.
